# Quad の求人原稿の型

実際に掲載している 359 件（介護 35・一般事務 57・軽作業 267）から抽出した型。
新規に書くときはこの型に合わせる。**汎用的な「きれいな求人原稿」ではなく、この型に寄せる**。

| 出典 | 件数 | 企業 | 職種 |
| --- | --- | --- | --- |
| 【求人共有_GB*Quad】 | 57 | 4th Avenue Lab / INK YOU UP | 介護職・一般事務 |
| マンパワー　求人 | 35 | マンパワーグループ | 一般事務 |
| 求人-20260818103741.xlsx | 267 | EatLABO | 倉庫作業・事務・営業 |

## 職種名

実測: 全角 9.5〜32 文字、平均 16.2 文字。

```
未経験｜介護施設のオープニングスタッフ｜練馬
未経験｜一般事務｜西新宿
未経験｜仕分け・梱包作業｜ひたちなか市
『未経験』事務職/マンパワーグループ株式会社/札幌支店
```

型は `<訴求語>｜<職種>｜<地名>`。守るのは次の 3 点。

- **先頭は訴求語**（`未経験` が最多）。求職者の検索語そのものなので左端に置く。
- **末尾は地名**（駅名または市区町村）。エリア検索に当てるための位置で、これを
  中央や先頭に動かすと同一企業の求人どうしが検索結果で見分けられなくなる。
- **区切りは全角 `｜`** で統一する。実データには半角 `|` の求人が混在しているが、
  表記が揺れると同じ企業の求人が別物に見える。新規は全角に寄せる。

エリア展開で同じ職種を何十件も出すときは、**職種の言い換えを 2〜3 種類用意して回す**。
実データではこうしている。

```
未経験｜介護施設のオープニングスタッフ｜練馬
未経験｜新規オープンの介護施設スタッフ｜糀谷
未経験｜新設老人ホームの生活補助スタッフ｜獨協大学前
```

同一文言を 35 件並べると媒体の重複判定に触れる。言い換えを回すのはその回避策。

### 職種名に「OK」「歓迎」を使わない

**職種名（タイトル）に `OK` `歓迎` の語を入れない。**
`未経験OK｜…` `未経験歓迎｜…` はどちらも使わない。

キャッチコピー・仕事内容・アピールポイントは対象外で、職種名の列だけの規則。
2026-09-24 に追加した。それ以前の納品物は作り直していないため、
過去の `deliverables/` 配下には `未経験OK` で始まる職種名が残っている。

使える訴求語は次のとおり。いずれも `OK` `歓迎` を含まない。

| 接頭辞 | 使いどころ |
| --- | --- |
| `未経験から` | 経験不問の求人全般。最も汎用的 |
| `経験不問` | 応募資格に経験を求めない求人 |
| `未経験スタート` | 入社後に覚える前提の求人 |
| `資格不要` | 資格を要件にしない求人 |
| `業界未経験から` | 同職種の経験は要るが業界は問わない求人 |
| `内勤中心` | 訪問や外まわりのない求人 |
| `訪問なし` | 非対面・内勤の営業職 |
| `もくもく作業` | 単独で進める作業系の求人 |
| `駅チカ` | 勤務地の近さが訴求になる求人 |
| `シフト相談` | 勤務時間に幅がある求人 |

`未経験` を単独で使うのも従来どおり可（実データで最多の形）。

なお「業界未経験から」のように、応募資格に経験を求める求人で `未経験` を
単独で使うと誤認を招く。タマホームの例のように、何が未経験でよいのかを
はっきりさせる。

## 求人キャッチコピー

全角 18 文字前後が主流。長いものでも 54 文字。

```
20代活躍中◎初めての事務職デビュー♪
20代活躍中◎初めての軽作業デビュー♪
【オープニング募集】全員同期スタートで人間関係の心配なし！きれいな新設施設で働く介護の正社員♪
＼飛び込み・テレアポ一切なし！／内勤メインの反響営業だから未経験でもカンタンに始められて、しっかり稼げます！
```

型は `<ターゲット層>◎<始めやすさ>♪` か `【<状況>】<差別化>`。
使う記号は `◎ ♪ ✨ 【】 ＼／ ×`。

### キャッチコピーに給与額を書かない

**月給・年収・時給・日給などの金額をキャッチコピーに入れない。**
給与は `給与（最低額）` 欄と本文で扱う。

理由は 2 つある。給与欄と別の場所に金額を書くと、片方だけ改定されたときに
食い違って労働条件の誤認表示になる。また、エリア展開で拠点ごとに給与が違う案件では
キャッチコピーは全行同一なので、そもそも正しい金額を書けない。

金額の代わりに、その求人でしか言えない条件を置く。

| 書かない | 書く |
| --- | --- |
| 月給27.8万円〜◎個人ノルマなしの買取スタッフ♪ | 個人ノルマなし◎売り込まない買取スタッフ♪ |
| 月給35万円〜◎業界最大手のブランド買取 | 全国1700店舗◎来店型だから飛び込みなし♪ |
| 年収1000万円も目指せる営業職 | 反響営業だからテレアポ・飛び込みなし◎ |

年齢・性別に触れる表現を入れないのも同じ（`references/legal.md`）。

## 本文の装飾

一般的な求人原稿の作法（記号を絞る、装飾を減らす）とは**意図的に違う**。
Indeed のアプリはプレーンテキストを詰めて表示するため、記号で塊を作らないと
読み飛ばされる。実データはこの記号体系で統一されている。

| 用途 | 記号 |
| --- | --- |
| 囲みキャッチ | `✦・━━━━━━━━━━━━━━━・✦` |
| セクション区切り | `＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝` |
| 見出し | `【✨この職場の魅力✨】` `《✼当施設の魅力✼》` |
| 箇条書き（魅力） | `✅` `✔` `✧` `◎` |
| 箇条書き（業務） | `■` |
| 呼びかけ | `＼〜／` |
| 装飾罫 | `✩.。...........................。.✩` |

1 行は全角 20〜25 文字で改行し、ブロックごとに空行を入れる。

### 箇条書きの項目どうしを空行で離さない

**`■` と `✔` の項目のあいだに空行を入れない。**
空行はセクションの区切り（`＝＝＝` の罫線）と見出し（`【】` `《》`）の前後にだけ置く。

```
【✧お仕事の内容✧】
■ ご相談の受付（お問い合わせ・ご紹介への対応）
■ ヒアリング（ご家族構成・働き方・将来のご予定）
■ ご状況の整理（今の備えの確認）
■ ご提案（ご状況に合う保障内容のご説明）
■ アフターフォロー（ご契約後のご相談対応）

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
【✨はじめての方へ✨】
✔ 経験・資格は必要ありません
✔ 手順はマニュアルで決まっています
✔ 接客や電話対応はありません
```

項目に説明の行をぶら下げるときも、次の項目とのあいだに空行を入れない。

```
■ 検品
伝票やチェックリストと照らして、品番と数量を確認します。
■ 梱包
商品を緩衝材で包み、指定のサイズの箱に詰めます。
```

`✅` の見出し付きブロック（アピールポイントで使う形）はこの規則の対象外で、
従来どおりブロックのあいだに空行を置く。

2026-09-24 に追加した規則。それ以前の納品物は作り直していない。

## 仕事内容の構成

```
✦・━━━━━━━━━━━━━━━・✦
＼未経験から"介護のプロ"へ！／
資格取得もキャリアアップも応援◎
✦・━━━━━━━━━━━━━━━・✦

「介護に興味はあるけど経験がない…」
そんな方も安心して始められる環境です。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
【✨この職場の魅力✨】

✅ 未経験でも安心の研修制度
先輩スタッフが丁寧にサポート！

✅ キャリアアップも目指せる
資格取得支援制度も充実しています。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
【✧お仕事内容✧】

■ 食事・入浴などの介助
■ レクリエーションの企画・運営
■ 利用者様の見守り

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
【✨働きやすいポイント✨】

✔ 月給30万円以上も目指せる！
✔ 残業少なめ（月5時間程度）
✔ 有給取得しやすい環境

「人の役に立つ仕事がしたい」
そんな方をお待ちしています！
```

順序は **囲みキャッチ → 共感の問いかけ → 職場の魅力 → 業務内容 → 働きやすさ → 締め**。
業務内容を先頭に置かないのは、未経験者は「自分にできるか」を先に知りたいため。
経験者採用（有資格・即戦力）のときは業務内容を先頭に上げる。

長文の求人（EatLABO 事務職）では、この後に
**【1日のスケジュール例】→【入社後の流れ】→【ここがポイント！】** が続く。
未経験ターゲットではこの 3 ブロックが効くので、情報があるなら入れる。

## 各欄の役割

| 欄 | 入れるもの |
| --- | --- |
| 募集要項（仕事内容） | 上記の構成。本体 |
| 募集要項（アピールポイント） | 会社・施設側の魅力。イベント、設備、資格支援制度 |
| 募集要項（求める人材） | 【応募資格】→ ★歓迎条件 → ▼こんな方におすすめ▼ |
| 募集要項（勤務時間・曜日） | シフトパターン、残業実績、残業代の扱い |
| 募集要項（休暇・休日） | `✅ 完全週休2日制` 形式で列挙 |
| 募集要項（給与の補足） | 昇給・賞与・各種手当 |
| 募集要項（待遇・福利厚生） | 保険、手当、制度の列挙 |
| 募集要項（その他） | 選考フロー。**変更の範囲もここに書く**（後述） |

### 選考フローの定型

実データでは全社ほぼ同一の文面を使っている。新規もこれに合わせる。

```
【選考のご案内】
＼選考ではなく、ご質問やご相談も歓迎／
「職務内容を詳しく知りたい」
「自分でも就業が可能か相談したい」など、
お気軽にご連絡ください。

＝＝＝＝＝＝＝＝＝＝
＼ お電話での相談受付中 ／
＝＝＝＝＝＝＝＝＝＝
・来社不要・履歴書不要・30分程度
＝＝＝＝＝＝＝＝＝＝

＜選考の手順＞
※重複応募防止のため、
お一人様一回までのご応募となります。

【1】簡単応募（1分程度で完了）
【2】お電話での事前面談
【3】（施設見学）および面接
【4】内定
```

## 年齢制限の書き方

実データでは 359 件中 310 件が 35 歳以下の募集で、全件に例外事由を明記している。
この書き方をそのまま使う。

```
例外事由3号のイにより、長期キャリア形成を図るため、
35歳以下を募集しております。
```

この例外が使えるのは **期間の定めのない労働契約** かつ **職務経験を不問とする** 場合に限る。
経験者採用に転用すると例外事由が成立せず違法になるので、経験を要件に入れた求人には書かない。

## 変更の範囲（全件で欠落している）

Indeed の入力シートに専用列がないため、実データ 359 件すべてで
**就業場所の変更の範囲・従事すべき業務の変更の範囲が未記載**になっている。
2024/4/1 施行の明示義務なので、新規で作るものには `募集要項（その他）` の末尾に必ず入れる。

```
＝＝＝＝＝＝＝＝＝＝
＜労働条件の明示＞
■ 就業場所の変更の範囲
変更なし（本求人の勤務地のみ）
■ 従事すべき業務の変更の範囲
変更なし（本求人の業務のみ）
```

転勤や職種転換がある場合は「会社の定める事業所」「会社の定める業務全般」と書く。
**変更がない場合も「変更なし」と書く。** 無記載は明示義務違反になる。
