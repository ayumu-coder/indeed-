引っかかった項目は、指摘だけで終わらせず修正後の文面まで示す。

## 年齢制限の例外（書ける場合）

年齢を書けるのは以下に該当するときのみ。原稿に**例外事由と理由を併記**する。

1. 定年年齢を上限として、期間の定めのない労働契約で募集する
2. 労働基準法等で年齢制限が定められている（例：深夜業を伴うため 18 歳以上）
3. 長期勤続によるキャリア形成のため、若年者を期間の定めのない契約で募集する（職務経験は不問とすること）
4. 技能・ノウハウの継承のため、特定年齢層が著しく少ない職種で募集する
5. 芸術・芸能分野で表現上の必要がある
6. 高年齢者・特定年齢層の雇用促進施策の対象者に限定する

## 落としやすい 3 点の書き方

### 固定残業代（3 点セット）

3 つのうち 1 つでも欠けると違法表示になる。

```
固定残業代 40,000円（時間外労働20時間分）を含む。
20時間を超える時間外労働分は別途支給。
```

①額 40,000円 ②相当時間数 20時間分 ③超過分別途支給 — この 3 つが揃っているか毎回確認する。

### 変更の範囲（2024/4/1 施行）

「現時点の就業場所・業務」に加えて、**将来の変更がありうる範囲**まで明示する義務がある。

```
■ 就業場所の変更の範囲
会社の定める事業所（転勤なし。大阪市内の営業所間の異動あり）
■ 従事すべき業務の変更の範囲
会社の定める業務全般（営業部内の他エリア担当への変更を含む）
```

変更がない場合も「変更なし」と書く。無記載は明示義務違反。

### 有期契約

期間の定めがある場合、次をすべて書く。

- 契約期間と更新の有無、更新の判断基準
- 通算契約期間または更新回数の上限（定めがある場合）
- 無期転換申込権が発生する契約更新時は、申込機会と転換後の労働条件

### 試用期間

試用期間中に労働条件が変わる場合は、その条件を明示する。
書かなかった場合は本採用の条件が適用されると解釈されうるため、企業側のリスクになる。

```
試用期間：3ヶ月（期間中の給与 月給230,000円、その他の条件に変更なし）
```
