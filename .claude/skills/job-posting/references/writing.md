## 文字数・体裁の目安

掲載媒体の仕様は変わるため、入稿前に最新の管理画面で確認する。

| 項目 | 目安 |
| --- | --- |
| 職種名 | 全角 30 文字以内（先頭 20 文字が勝負） |
| 仕事内容 | 全角 400〜1,200 文字 |
| 1 行の長さ | 全角 30 文字前後で改行（スマホ想定） |
| 段落 | 3〜4 行ごとに空行 |
| 装飾記号 | `references/house-style.md` の記号体系に従う（Indeed アプリは詰めて表示するため、記号で塊を作らないと読み飛ばされる） |

## 職種名の組み立て

構成は `<訴求語>｜<職種>｜<地名>`。実データ 359 件から抽出した型で、
詳細と実例は `house-style.md` にある。

```
未経験｜介護施設のオープニングスタッフ｜練馬
未経験｜一般事務｜西新宿
```

スマホの検索結果では**先頭 15〜20 文字**しか表示されない。求職者が実際に検索窓へ
打ち込む語（一般名詞）を左に寄せ、エリア検索に当てる地名を末尾に置く。

含めないもの: 給与額、記号の乱用（★☆【】の連打）、企業のキャッチコピー、
複数職種の併記（1 求人 1 職種）。

社内造語・社内略語は検索されないので一般名詞に開く。

| 社内表記 | 原稿での表記 |
| --- | --- |
| CS職 | カスタマーサポート |
| BR（ビジネスレップ） | 法人営業 |
| PM職 | プロジェクトマネージャー |

## 仕事内容の書き方

冒頭 2〜3 行で「**誰が・何を・誰に対して**」が分かるようにする。
検索結果のスニペットに出るのがこの部分で、ここで読むかどうかが決まる。

抽象語は情報量がゼロなので、求職者は自分に当てはまるか判断できず読み飛ばす。動詞で書く。

| 抽象的 | 具体的 |
| --- | --- |
| 幅広い業務をお任せします | 既存取引先40社への提案、受発注入力、納期調整 |
| 営業活動全般 | 週2〜3回の既存店舗訪問と発注ヒアリング |
| 各種事務作業 | 請求書作成（月80件）、経費精算チェック、来客対応 |

「1 日の流れ」は入社後の生活が想像できるので応募率に効く。時刻付きで書く。

## 主観形容詞を事実に置き換える

企業の自己申告である形容詞は、求職者に信用されない。数字か検証可能な事実に置き換える。

| 主観形容詞 | 置き換え |
| --- | --- |
| アットホームな職場 | 平均年齢32歳、20〜30代が7割 |
| 風通しが良い | 月1回、代表と全社員の1on1あり |
| 未経験でも安心 | 入社後3ヶ月は先輩が同行。直近3年の未経験入社6名中5名が在籍 |
| 残業は少なめ | 月平均残業12.4時間（2025年度実績） |
| 成長できる環境 | 資格取得費用を全額補助（直近2年で8名が◯◯士を取得） |

数字が出てこない場合、その訴求は実態がない可能性が高い。盛るのではなく、
別の訴求に差し替えるか「誰にとってなら魅力か」を絞る。

## 掲載品質チェック（検索対策）

- [ ] 1 求人 1 職種 1 勤務地になっている（まとめ求人は掲載停止リスク）
- [ ] 職種名・仕事内容に、求職者が実際に検索する語（一般名詞）が入っている
- [ ] 社内造語・社内略語を使っていない（`CS職` → `カスタマーサポート`）
- [ ] 同一企業の他求人と原稿が重複していない
- [ ] 応募 URL・応募方法が有効
- [ ] 連絡先が個人の私用メールアドレス・私用電話番号になっていない
- [ ] 誤字脱字、全角半角の混在、企業名の表記ゆれがない
- [ ] 掲載終了した募集の使い回しでない（募集終了求人の放置は掲載品質を下げる）

## 記入例（ルート営業）

> **職種名**
> 未経験歓迎｜ルート営業（大阪市北区／年間休日125日）
>
> **仕事内容**
> ■ 業務概要
> 既存取引先（食品スーパー・ドラッグストア 約40社）へ自社食品の提案と受発注対応を行います。新規開拓はありません。
>
> ■ 具体的な業務
> ・担当エリア（大阪市内）の既存店舗を週2〜3回訪問し、発注数量をヒアリング
> ・新商品の提案資料作成と売場提案
> ・受注データの基幹システム入力、納期調整
>
> ■ 1日の流れ
> 9:00 出社・メール確認 / 10:00 訪問（3〜4件）/ 12:00 昼休憩 / 13:00 訪問（2〜3件）/ 16:00 帰社・受注入力 / 18:00 退社
>
> ■ 従事すべき業務の変更の範囲
> 会社の定める業務全般（営業部内の他エリア担当への変更を含む）
>
> **給与**
> 月給 250,000円 〜 350,000円（経験・能力を考慮のうえ決定）
>
> ■ 固定残業代
> 固定残業代 40,000円（時間外労働20時間分）を含む。20時間を超える時間外労働分は別途支給。
>
> ■ 昇給・賞与
> 昇給 年1回（4月）／賞与 年2回（7月・12月／前年度実績 計3.2ヶ月分）
>
> **勤務地**
> 大阪府大阪市北区◯◯1-2-3 ◯◯ビル5F
> 最寄駅：JR大阪駅（徒歩8分）
> 受動喫煙防止措置：屋内禁煙（屋外に喫煙所あり）
>
> ■ 就業場所の変更の範囲
> 会社の定める事業所（転勤なし。大阪市内の営業所間の異動あり）
>
> **応募資格**
> 【必須】普通自動車第一種運転免許（AT限定可）
> 【歓迎】法人営業の経験、食品業界での就業経験
>
> **この求人の魅力**
> ・年間休日125日、土日祝休み。月平均残業時間は12.4時間（2025年度実績）
> ・既存顧客のみのため、飛び込み営業・テレアポは一切なし
> ・入社後3ヶ月は先輩社員が同行。未経験入社が直近3年で6名中5名
