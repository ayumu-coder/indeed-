## 前提・掲載しなかった情報

法令およびハウスルールにより、依頼元資料にある以下は原稿に含めていない。

| 元資料の記載 | 対応 |
| --- | --- |
| 年齢層 18歳〜39歳（飲食経験者は〜45歳） | 不掲載（年齢表現を使わない） |
| 性別に関する記述、炭火焼の火傷リスクを性別と結びつけた説明 | 火傷リスクは性別と切り離し、職場環境の事実として記載 |
| 「奥様が日本人」 | 不掲載（配偶者の属性による選別にあたる） |
| 国籍要件 | 「日本語能力試験N1相当以上」「就労が認められる在留資格」という業務上必要な能力・資格要件として記載 |
| 募集背景のうち社員の不正に関する記述 | 不掲載。募集背景は「事業展開に伴う増員」のみ |
| 他店舗（鶴舞）に関する内部事情 | 不掲載 |
| 採用単価などの社内条件 | 不掲載 |
| 「キャピキャピ」等の口語表現 | 「学生が中心で活気のある職場」に言い換え |

加えて、以下のルールを機械的に検証している（`求人入力シート/生成スクリプト/build15_toriaezu.py`）。

- 職種名・キャッチコピー・「募集要項（給与の補足）」以外の本文に給与額を含めない
- 職種名に「OK」「歓迎」を含めない
- `■` `✔` の箇条書きは項目間に空行を入れない（空行は見出しの前後のみ）
- 職種名・キャッチコピーが6行すべて異なる

## 未確定事項

掲載前に確認が必要な項目。該当箇所には `【要確認】` を明記している。

| 項目 | 内容 |
| --- | --- |
| 年間休日日数 | 商談メモは110日のみ。週休1日／隔週休2日／週休2日のどの区分に対応する日数か特定できない。区分ごとの日数が必要 |
| 固定残業代の金額 | 45時間分 78,600円〜98,200円という幅のみ。休日区分ごと・月給額ごとの金額が不明 |
| 月給上限 | 500,000円の適用条件（経験年数など）が不明 |
| 想定年収 | 商談メモに「448万円〜」と「実態は380万円〜」が併記。原稿には380万円〜を採用した |
| 所定労働時間 | 1日あたりの所定労働時間と時間外の内訳が不明。「平均所定労働時間」は暫定で160を入力 |
| 最寄駅・アクセス | 記載なし |
| 郵便番号 | 記載なし（空欄） |
| 一日の流れ | 商談メモの該当欄が空欄。原稿では勤務時間の記載で代替 |
| 「2原稿ずつ」の解釈 | 休日区分3種 × 訴求軸2案と解釈した。店長／店長候補の職種2種という意図であれば作り直しが必要 |
