## 対象外だが要対応（未変更）

1. **変更の範囲が 35 行とも未記載** — 就業場所・業務とも。`募集要項（その他）` に追記が必要。
   求める人材欄に「神戸周辺の店舗にて勤務していただく可能性もあります」とあるため
   「変更なし」とは書けない。
2. **タグ「残業なし」と勤務時間欄の矛盾** — 勤務時間欄は「月間平均残業時間：10時間以下」。
3. **休暇欄の文字化け（6 箇所）** — `年間休⽇：110⽇` の「⽇」が康熙部首（U+2F47）で、
   通常の「日」（U+65E5）ではない。「年間休日」で検索しても引っかからない。
4. **求める人材欄と勤務地の不一致** — 「大阪府内勤務可能な方」だが 35 店舗中 12 店舗が兵庫県。
