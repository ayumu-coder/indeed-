| ファイル | 内容 |

## 作成方針

- 業務は一般事務の一般的な範囲（データ入力、書類作成・ファイリング、電話・メール対応、来客対応、
  備品管理）にとどめた。取扱商品・部署構成・使用ツール名など、会社の実態が分からない具体情報は書いていない。
- 本文に書いた事実（9:00〜18:00 固定時間制、残業なし、社会保険完備、交通費支給、昇給年1回・賞与年2回、
  住宅手当・家族手当・皆勤手当、資格取得支援、健康診断、服装・ネイル自由、面接1回、履歴書任意）は
  すべて元データの引き継ぎ列（勤務時間・タグ・待遇・給与の補足・その他・履歴書の有無）にあるものだけ。
- キャッチコピーに給与額・年齢・性別は入れていない。元データの「20代が多数活躍中」は引き継いでいない。
- 文体・記号体系は `.claude/skills/job-posting/references/house-style.md` に従った。
- 職種名は 3 パターン、キャッチコピーは 5 パターン、仕事内容は 3 パターンを行順に循環させている。
  仕事内容には駅名と住所を差し込んでいるので 50 行すべて別文面（媒体の重複判定対策）。
  職種名の区切りは house-style の全角 `｜` ではなく、同社の既存 50 件（`《未経験》検品・梱包作業/日吉`）
  と並んだときに同じシリーズに見えるよう、依頼の例示どおり `《未経験OK》一般事務/日吉` の形にした。

## 元データの要確認事項（修正していない。両シリーズ共通）

1. **休暇・休日列が原稿ではなくメモ**。`* *完全週休2日制（土日祝休み）*: カレンダー通りに休みたい人向け。…`
   `* *年間休日120日以上*: 大手企業の倉庫や工場に多いパターン。「仕事のために生きてるわけじゃない」という層に刺さる数字。`
   という企画メモの文面がそのまま入っている。「倉庫や工場」の語もあり、一般事務では掲載できない。
   条件が正しいなら次の差し替えを推奨。
   ```
   ✅ 完全週休2日制（土日祝休み）
   ✅ 年間休日120日以上
   ```
2. **キャッチコピーの年齢表現**「＼20代が多数活躍中／」。在籍者構成の表現で違反ではないが、
   募集条件の文脈と読まれうる（リンタ `age-soft`）。一般事務側には引き継いでいない。
3. **応募者に関する情報に「性別」**が含まれている（リンタ `applicant-gender`）。選考に使わないなら外す
   （`assets/indeed-upload-columns.md`「原則外す」）。指示どおり引き継いだため一般事務側にも残っている。
4. **就業場所・業務の変更の範囲が未記載**（2024/4/1 施行の明示ルール。リンタ error 100 件）。
   一般事務側は「変更なし」で追記したが、**転勤・拠点間異動・職種転換の有無は元データに情報がなく未確認**。
   異動があるなら「会社の定める事業所」等に書き換えが必要。軽作業側も追記が必要。
5. **受動喫煙防止措置の記載がない**（健康増進法。両シリーズとも）。
6. **仕事内容が 50 行完全同一**（リンタ `duplicate`）。媒体の重複判定に触れる。
7. **勤務地の住所に番地が入っている行と町名止まりの行が混在**（例: 日吉 `2-1-1` / 出町柳 `田中下柳町`）。
   駅の所在地を勤務地として使っているため、実際の就業場所と一致しているか要確認。
8. **年齢制限（39 歳以下・例外事由 3 号のイ）**は、期間の定めのない正社員かつ職務経験不問の場合のみ成立する。
   両シリーズとも正社員・未経験可なので成立するが、経験を要件に加える場合は削除が必要。
9. 職種名の区切りが半角 `/`（house-style は全角 `｜`）。今回は同社の既存分に合わせた。
