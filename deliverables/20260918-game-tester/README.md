## 作成方針

会社名・給与・勤務時間・待遇は依頼に含まれていないため、**一切書いていない**。
推測で書けば虚偽の労働条件明示になる（職業安定法 65 条）。
条件に触れる必要がある箇所は「給与・勤務時間・シフトなどの詳細は、ご応募後にご案内します」
にとどめてある。

**特定のゲームタイトル名・開発会社名・ハード名は書いていない。**
検証器で社名・機種名の混入も検出している。

仕事内容に書いた業務（テスト仕様書に沿ったプレイ、不具合の再現確認、
所定フォーマットでの報告、チェックリスト記入）はゲームテスター一般の内容であり、
特定の事業者の設備や制度を指すものではない。

文面は `.claude/skills/job-posting/references/house-style.md` の記号体系と構成に従った。
キャッチコピーに給与額を入れない規則（2026-09-16 追加）に従っている。
年齢・性別に触れる表現も使っていない。

## リンタ結果

`lint_sheet.py` は Indeed の 67 列シート用でこの 7 列 CSV には直接当てられないため、
同じ判定ロジック（`scripts/rules.py`）をこの 7 列に適用する `check.py` を用意した。
9/17 の愛知版の `check.py` を 7 列用に拡張したもの。

```bash
python3 check.py
# → 180 件 / エラー 0 件 / 警告 0 件
```

当てた項目:

| 検出 | 内容 |
| --- | --- |
| required | 7 列に空欄がないか |
| copy-wage | キャッチコピーに給与額が入っていないか |
| age-limit / age-soft | 年齢に触れる表現 |
| gender / physical / attribute / language | 性別・身体的要件・属性・言語要件 |
| placeholder | 未置換のプレースホルダ |
| title-length / title-separator | タイトルの全角 30 文字以内、区切りが全角 `｜` |
| catch-length | キャッチコピーの全角 30 文字以内 |
| address | 住所が当該都道府県で始まるか |
| station-title / station-body | タイトルと仕事内容に駅名が入っているか |
| address-body | 仕事内容に勤務地が入っているか |
| brand | 特定の社名・機種名（任天堂／ソニー／Switch／PlayStation ほか）の混入 |
| pref-count | 都道府県ごとに 10 行か |
| duplicate-station / duplicate-title | 駅名・タイトルの重複 |

検出器が空振りしていないことは、意図的に違反させた行を通して 13 件検出されることで確認した。

## 掲載前に必要なもの（この CSV には含まれていない）

7 列だけの原稿なので、このままでは掲載できない。少なくとも次が要る。

- 会社名、雇用形態、給与形態・給与額、勤務時間、休日休暇、加入保険
- **就業場所の変更の範囲／従事すべき業務の変更の範囲**（2024/4/1 施行の明示ルール）
- 固定残業代がある場合は額・相当時間数・超過分別途支給の 3 点
- 受動喫煙防止措置
