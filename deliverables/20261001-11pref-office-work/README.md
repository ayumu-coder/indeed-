## 先に申し送り：性別に言及していない

依頼は「女性応募がたくさん来るように」だが、**「女性歓迎」「女性活躍中」のような
性別に言及する表現は入れていない**。男女雇用機会均等法 5 条が募集・採用における
性別を理由とする差別を禁じており、Indeed 側の審査でも落ちる。

代わりに、条件そのもので同じターゲットに届く形にした。

- ライブ・舞台・遠征の予定を立てて働ける（定時退社・希望休）
- ネイル・ヘアカラー・服装の自由度を応募前に確認できる
- 未経験・資格不要、座って進めるデスクワーク、社外営業なし

`check.py` はこの訴求軸が全行に入っていることを `no-appeal` で確認し、
`rules.py` の `gender` 判定で性別表現の混入を弾く。

## 断定していないこと（STRICT フラグ）

事業者の実態（ネイル・髪色・服装の可否、休暇の取りやすさ、残業の有無）は
与えられていない。断定すれば職業安定法 5 条の 3・65 条の虚偽の条件表示になるため、
「職場ごとに異なります／選考の場で確認できます」という書き方にしている。

実態を確認できた案件では `gen.py` の `STRICT = False` にすると
`PRIVATE_STRICT`（「ネイル・ヘアカラーは自由です」など断定形）に切り替わる。
**事業者の確認が取れるまで `True` のままにすること。**

## 原稿の作り分け

55 = 11 × 5 なので、行を決める自由度は `(r, q) = (i % 5, i // 5)` の 2 つだけ。
本文の 6 ブロックに `(r + k·q) mod 5`（k は 0〜4 で相異なる）を割り当てており、
任意の 2 行で一致するブロックは必ず 1 個以下になる。

当初 `i // 2`, `i // 3` のような取り方をしたところ周期が重なり、
`lint_posting.py` の重複判定で本文が最大 75% 一致していた。
現在の最大一致率は 58%（既定の閾値 0.6 未満）。

## 住所の確度

`stations_top5.py` の 4 番目の要素が `False` の駅は、住所が市区町村までしか
特定できていない（京都府の 四条・烏丸 / 京都河原町 / 丹波橋 の 3 件）。
入稿前に実際の勤務地住所へ差し替えること。

複合駅名（南越谷・新越谷、梅田・大阪、天王寺・阿部野橋、四条・烏丸）は、
職種名では主駅名のみを使っている。併記すると全角 30 を食い、
`lint_sheet.py` の `location-mismatch`（職種名の地名が住所に現れない）に当たる。
併記は本文の勤務地行で行っている。
