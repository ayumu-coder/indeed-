# 求人原稿作成テンプレート（Indeed 掲載用）

株式会社Quad が求人原稿を作成するための雛形。
`{{ }}` を埋めれば原稿が完成し、そのまま LLM への入力プロンプトとしても使える。

- **手書きで使う場合**: セクション 0 を埋め → セクション 1 を書き → セクション 3・4 で検品。
- **LLM に書かせる場合**: セクション 0 を埋めたこのファイル全体を渡し、「セクション 1 を出力せよ」と指示する。

## 1. 求人原稿（納品物）

### 職種名

```
{{jobTitleCopy}}
```

- 目安 全角 30 文字以内。スマホ検索結果では**先頭 15〜20 文字**しか見えない前提で、左側に検索語を置く。
- 構成: `[地名 or 雇用形態] + 職種名 + 訴求1つ` 例）`未経験歓迎｜ルート営業（大阪市北区／年間休日125日）`
- 職種名に含めない: 給与額、記号の乱用（★☆【】の連打）、企業のキャッチコピー、複数職種の併記（**1求人1職種**）。

### 仕事内容

```
■ 業務概要
{{jobSummary}}

■ 具体的な業務
・{{task1}}
・{{task2}}
・{{task3}}

■ 1日の流れ
{{dailySchedule}}

■ 入社後のフォロー
{{onboarding}}

■ 従事すべき業務の変更の範囲
{{taskChangeScope}}
```

- 冒頭 2〜3 行で「誰が・何を・誰に対して」が分かるようにする（検索結果のスニペットに出る）。
- 抽象語（`幅広い業務`／`色々な仕事`）は禁止。動詞で書く。
- **業務の変更の範囲**は 2024/4/1 施行の労働条件明示ルールで必須。

### 給与

```
{{payType}} {{payMin}}円 〜 {{payMax}}円

■ 固定残業代
{{fixedOvertime}}

■ 昇給・賞与
{{raiseBonus}}

■ モデル年収
{{modelIncome}}
```

- 下限額は**必ず最低賃金以上**（地域別最低賃金の改定月をまたぐ原稿は要再確認）。
- レンジ表示のとき「経験・能力を考慮し決定」を添える。上限だけの表示（`〜50万円`）は不可。
- 固定残業代がある場合は **3点セットを必ず明示**: ①固定残業代の額 ②相当する時間数 ③超過分は別途支給する旨。1つでも欠けると違法表示。

### 勤務地

```
{{workLocation}}
最寄駅：{{nearestStation}}（徒歩{{walkMinutes}}分）
受動喫煙防止措置：{{smokingPolicy}}

■ 就業場所の変更の範囲
{{locationChangeScope}}
```

- 「本社および各支店」だけの表記は不可。実際に就業する住所を書く。
- 転勤の有無を明記する。

### 勤務時間・休日休暇

```
勤務時間：{{workingHours}}（休憩{{breakMinutes}}分／所定労働{{contractedHours}}時間）
時間外労働：{{overtime}}
休日：{{holidays}}（年間休日{{annualHolidays}}日）
休暇：{{leaves}}
```

### 応募資格

```
【必須】
・{{requiredSkills}}

【歓迎】
・{{preferredSkills}}
```

- 年齢・性別・国籍・居住地・家族構成による限定は**原則として書けない**（セクション 3 参照）。

### 待遇・福利厚生

```
・加入保険：{{insurance}}
・交通費：{{commuteAllowance}}（上限{{commuteCap}}円/月）
・{{benefits}}
```

### 雇用形態・契約期間

```
雇用形態：{{employmentType}}
契約期間：{{contractPeriod}}
試用期間：{{probation}}（期間中の労働条件：{{probationTerms}}）
```

- 有期契約なら**更新の有無・更新上限・無期転換申込機会と転換後の労働条件**まで書く。
- 試用期間中に条件が下がる場合は、その条件を明示する（書かないと本採用条件が適用される）。

### 選考フロー

```
{{selectionFlow}}
（例：書類選考 → 一次面接（オンライン） → 最終面接 → 内定）
応募から内定まで：{{leadTime}}
```

### この求人の魅力（訴求）

```
・{{sellingPoint1}}
・{{sellingPoint2}}
・{{sellingPoint3}}
```

- 主観形容詞（`アットホーム`／`風通しが良い`）を**数字か事実に置き換える**。
  例）`アットホームな職場` → `平均年齢32歳・20〜30代が7割`

## 2. 文字数・体裁の目安

掲載媒体の仕様は変わるため、入稿前に最新の管理画面で確認する。

| 項目 | 目安 |
| --- | --- |
| 職種名 | 全角 30 文字以内（先頭 20 文字が勝負） |
| 仕事内容 | 全角 400〜1,200 文字 |
| 1 行の長さ | 全角 30 文字前後で改行（スマホ想定） |
| 段落 | 3〜4 行ごとに空行 |
| 装飾記号 | `■` `・` のみ。機種依存文字・過度な絵文字は使わない |

## 3. 法令チェック（入稿前に全項目 ✅ にする）

| # | チェック項目 | 根拠 |
| --- | --- | --- |
| 1 | 年齢制限を設けていない（例外事由に該当する場合のみ、その理由を明記） | 労働施策総合推進法 9 条 |
| 2 | 性別を限定していない（`営業マン`→`営業職`、`看護婦`→`看護師`） | 男女雇用機会均等法 5 条 |
| 3 | 国籍・信条・出身地・家族構成による限定がない | 職業安定法 3 条 |
| 4 | 業務に必要ない身体的条件（身長・体重・容姿）を要件にしていない | 均等法 7 条（間接差別） |
| 5 | 給与下限が地域別最低賃金以上 | 最低賃金法 |
| 6 | 固定残業代の 3 点セット（額・時間数・超過分別途支給）が揃っている | 職業安定法 5 条の 3 |
| 7 | 就業場所・業務内容の**変更の範囲**を明示している | 2024/4/1 施行の明示ルール |
| 8 | 有期契約の更新上限・無期転換に関する明示がある | 同上 |
| 9 | 受動喫煙防止措置を明示している | 健康増進法 |
| 10 | 実際の労働条件と原稿が一致している（誇大・虚偽表示なし） | 職業安定法 65 条（罰則） |
| 11 | 派遣・請負を雇用と誤認させる書き方をしていない | 労働者派遣法 |
| 12 | 応募者に金銭負担（登録料・研修費・教材費）を求めていない | — |

### 年齢制限の例外（書ける場合）

年齢を書けるのは以下に該当するときのみ。原稿に**例外事由と理由を併記**する。

1. 定年年齢を上限として、期間の定めのない労働契約で募集する
2. 労働基準法等で年齢制限が定められている（例：深夜業を伴うため 18 歳以上）
3. 長期勤続によるキャリア形成のため、若年者を期間の定めのない契約で募集する（職務経験は不問とすること）
4. 技能・ノウハウの継承のため、特定年齢層が著しく少ない職種で募集する
5. 芸術・芸能分野で表現上の必要がある
6. 高年齢者・特定年齢層の雇用促進施策の対象者に限定する

## 4. 掲載品質チェック（Indeed 検索対策）

- [ ] 1 求人 1 職種 1 勤務地になっている（まとめ求人は掲載停止リスク）
- [ ] 職種名・仕事内容に、求職者が実際に検索する語（一般名詞）が入っている
- [ ] 社内造語・社内略語を使っていない（`CS職` → `カスタマーサポート`）
- [ ] 同一企業の他求人と原稿が重複していない
- [ ] 応募 URL・応募方法が有効
- [ ] 連絡先が個人の私用メールアドレス・私用電話番号になっていない
- [ ] 誤字脱字、全角半角の混在、企業名の表記ゆれがない
- [ ] 掲載終了した募集の使い回しでない（募集終了求人の放置は掲載品質を下げる）

## 5. 記入例（ルート営業）

> **職種名**
> 未経験歓迎｜ルート営業（大阪市北区／年間休日125日）
>
> **仕事内容**
> ■ 業務概要
> 既存取引先（食品スーパー・ドラッグストア 約40社）へ自社食品の提案と受発注対応を行います。新規開拓はありません。
>
> ■ 具体的な業務
> ・担当エリア（大阪市内）の既存店舗を週2〜3回訪問し、発注数量をヒアリング
> ・新商品の提案資料作成と売場提案
> ・受注データの基幹システム入力、納期調整
>
> ■ 1日の流れ
> 9:00 出社・メール確認 / 10:00 訪問（3〜4件）/ 12:00 昼休憩 / 13:00 訪問（2〜3件）/ 16:00 帰社・受注入力 / 18:00 退社
>
> ■ 従事すべき業務の変更の範囲
> 会社の定める業務全般（営業部内の他エリア担当への変更を含む）
>
> **給与**
> 月給 250,000円 〜 350,000円（経験・能力を考慮のうえ決定）
>
> ■ 固定残業代
> 固定残業代 40,000円（時間外労働20時間分）を含む。20時間を超える時間外労働分は別途支給。
>
> ■ 昇給・賞与
> 昇給 年1回（4月）／賞与 年2回（7月・12月／前年度実績 計3.2ヶ月分）
>
> **勤務地**
> 大阪府大阪市北区◯◯1-2-3 ◯◯ビル5F
> 最寄駅：JR大阪駅（徒歩8分）
> 受動喫煙防止措置：屋内禁煙（屋外に喫煙所あり）
>
> ■ 就業場所の変更の範囲
> 会社の定める事業所（転勤なし。大阪市内の営業所間の異動あり）
>
> **応募資格**
> 【必須】普通自動車第一種運転免許（AT限定可）
> 【歓迎】法人営業の経験、食品業界での就業経験
>
> **この求人の魅力**
> ・年間休日125日、土日祝休み。月平均残業時間は12.4時間（2025年度実績）
> ・既存顧客のみのため、飛び込み営業・テレアポは一切なし
> ・入社後3ヶ月は先輩社員が同行。未経験入社が直近3年で6名中5名
