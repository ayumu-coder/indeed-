CSV は UTF-8 BOM 付き。セル内改行を含むため、スプレッドシートへは
「ファイル → インポート → 現在のシートに追加」を推奨（直接ペーストすると改行が行分割されます）。

## 作成ルール

- 原稿は依頼元（Slack `#人紹_indeed集客_quad` の依頼スレッド）および
  添付の求人票・ヒアリングシート・掲載原稿に準拠する。根拠のない具体情報は創作しない。
- 掲載原稿とヒアリング内容が食い違う場合は掲載原稿を正とし、差分を `【要確認】` に残す。
- 元情報で未確定の項目は空欄または `【要確認】` を明記する。
- 求人キャッチコピーに給与額（月給・年収・時給・日給・年俸）を入れない。
  給与は「給与」欄および「募集要項（給与の補足）」で扱う。
- 年齢・性別の要件および表現を原稿に用いない。
- 国籍による応募制限は掲載しない（職業安定法第3条／均等待遇原則）。
- 転職回数の上限など、選考の内部基準は原稿に記載しない。
- 企業名掲載不可の案件は、社名・自社URLを本文に含めない。
- 他社エージェントが作成した原稿本文はそのまま転記しない。事実のみを採り、表現は書き下ろす。

`生成スクリプト/build14.py` が、キャッチコピーへの給与額混入、年齢・性別表現、
他社エージェント情報の混入、キャッチコピーの重複を機械的に検証する。
