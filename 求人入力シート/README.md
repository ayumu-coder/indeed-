## ファイル

| パス | 内容 |
| --- | --- |
| `求人入力シート_v11_全10求人.csv` | 全求人をまとめた最新版（1行目ヘッダー、2行目以降がデータ） |
| `会社別/` | 会社単位で切り出したもの（貼り付け用） |
| `生成スクリプト/` | 各版を生成した Python スクリプト |

CSV は UTF-8 BOM 付き。セル内改行を含むため、スプレッドシートへは
「ファイル → インポート → 現在のシートに追加」を推奨（直接ペーストすると改行が行分割されます）。

## 作成ルール

- 原稿は依頼元（Slack `#人紹_indeed集客_quad` の依頼スレッド）および
  添付の求人票・ヒアリングシートに準拠する。根拠のない具体情報は創作しない。
- 元情報で未確定の項目は空欄または `【要確認】` を明記する。
- 求人キャッチコピーに給与額（月給・年収・時給・日給）を入れない。
- 年齢・性別の要件および表現を原稿に用いない。
- 国籍による応募制限は掲載しない（職業安定法第3条／均等待遇原則）。
- 転職回数の上限など、選考の内部基準は原稿に記載しない。
- 企業名掲載不可の案件は、社名・自社URLを本文に含めない。
