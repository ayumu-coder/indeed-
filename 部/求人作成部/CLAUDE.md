## ルール

- キャッチコピー・タイトル・本文 (仕事内容・アピール・応募資格) に給与額を書かない。給与額は給与欄と「募集要項 (給与の補足)」のみ。
- タイトル (職種名) に「OK」「歓迎」を入れない。
- ■ / ✔ の箇条書きは項目間に空行を入れない (✅ ブロックは除く)。
- 本文に【要確認】等の注記を残さず、未確定事項は README に集約する。
- 年齢・性別・国籍の表現は原稿のどこにも書かない (元資料にあっても不掲載)。担当者名・エージェント向け記述・社内の選考基準も不掲載。
- 同一会社の複数求人は職種名とキャッチコピーを書き分ける (Indeed の重複判定対策)。
- 元資料に「⇒質問 / →回答」の打ち合わせメモが混在する場合は確定内容のみ反映。
- 成果物は `deliverables/<日付>_<案件名>/` に CSV + README (判断事項・未確定事項の一覧) を置き commit・push。生成スクリプトは `求人入力シート/生成スクリプト/`。
- 低給与の目安 (README でマーク、除外はしない): 月給下限 25 万円未満 または 年収下限 350 万円未満。
